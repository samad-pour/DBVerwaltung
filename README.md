# DBVerwaltung

Ein Softwareprojekt zur Verwaltung und Bearbeitung von Datenbankeinträgen innerhalb einer Anwendung.

## Beschreibung

Das Projekt **DBVerwaltung** beschäftigt sich mit den Grundlagen der Datenbankverwaltung. Im Mittelpunkt stehen die Organisation, Speicherung und Bearbeitung von Daten sowie die Interaktion zwischen einer Anwendung und einer Datenbank.

## Funktionen

- Verwaltung von Datenbankeinträgen
- Hinzufügen neuer Datensätze
- Anzeigen gespeicherter Informationen
- Bearbeiten bestehender Datensätze
- Löschen von Datenbankeinträgen
- Grundlagen der CRUD-Operationen (Create, Read, Update, Delete)

## Technologien

- Microsoft Visual Studio
- Datenbankanbindung
- SQL-Grundlagen

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/DBVerwaltung.git
   ```

2. Das Projekt in Visual Studio öffnen.
3. Falls erforderlich, die Datenbankverbindung konfigurieren.
4. Das Projekt erstellen.
5. Die Anwendung starten.

## Ziel

Das Projekt dient dem Verständnis grundlegender Datenbankoperationen und der praktischen Umsetzung einer Datenverwaltung. Dabei werden wichtige Konzepte wie Datenbankverbindungen, SQL-Abfragen und CRUD-Operationen behandelt.
